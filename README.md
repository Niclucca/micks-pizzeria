# MICK'S PIZZERIA

**Sitio web conceptual para una pizzería.**

MICK'S PIZZERIA es un proyecto personal de desarrollo web frontend, creado como parte de un portfolio profesional.

El proyecto busca desarrollar una experiencia web con identidad visual propia, combinando una presentación atractiva, una carta de productos y secciones informativas para representar la presencia digital de una pizzería.

## Características implementadas

- Página principal con presentación del establecimiento.
- Sección de menú con productos.
- Sección dedicada a la historia del establecimiento.
- Navegación entre las diferentes secciones.
- Menú de navegación móvil interactivo.
- Animaciones de aparición al desplazarse por la página.
- Formulario de reservas con validación de campos.
- Generación de un código de reserva y confirmación visual.
- Secciones de horarios, ubicación y contacto.
- Diseño adaptable a diferentes tamaños de pantalla.
- Consideración de la preferencia de movimiento reducido del usuario.

## Tecnologías utilizadas

- **HTML5:** estructura y contenido.
- **CSS3:** diseño visual, estilos, animaciones y adaptación responsive.
- **JavaScript ES6+:** interactividad y comportamiento de la interfaz.
- **Google Fonts:** tipografías Fraunces, Libre Baskerville, Yesteryear y Courier Prime.

El proyecto utiliza JavaScript nativo, sin frameworks ni dependencias externas de JavaScript.

## Requisitos

- Un navegador web moderno.
- Conexión a internet para cargar las tipografías desde Google Fonts.

No requiere Node.js, npm ni herramientas de construcción para su ejecución actual.

## Instalación y ejecución local

Cloná el repositorio:

```bash
git clone https://github.com/Niclucca/micks-pizzeria.git
```

Ingresá a la carpeta:

```bash
cd micks-pizzeria
```

Abrí `index.html` directamente en el navegador para visualizar el sitio.

## Estado actual y mejoras futuras

El proyecto cuenta con una interfaz frontend desarrollada y distintas interacciones implementadas mediante JavaScript.

Actualmente, el formulario de reservas funciona como una demostración visual: valida los campos, genera un código y muestra una confirmación local, pero no envía información a un servidor ni registra reservas reales.

Entre las posibles mejoras futuras se encuentran:

- Implementación de un sistema real de reservas.
- Integración de almacenamiento y gestión de reservas.
- Incorporación de perfiles reales de redes sociales.
- Revisión y unificación de los datos de contacto.
- Mejoras adicionales de accesibilidad.
- Optimización de los metadatos para buscadores y redes sociales.
